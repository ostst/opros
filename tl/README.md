# Анкета ТЛ (РАНХиГС × Академия ПСБ)

Папка `tl/` лежит внутри репозитория старого опроса и использует тот же Firebase (`../assets/firebase-config.js`). Ответы пишутся в отдельный документ `poll/tl-2026`, со старым опросом не смешиваются. Правила Firestore менять не нужно.

## Страницы

| Файл | Для кого |
|---|---|
| `tl/` (index.html) | Участники, сюда ведёт QR-код |
| `tl/results.html` | Большой экран: пока результаты скрыты — QR и счётчик, после включения — живые итоги, как в Mentimeter |
| `tl/admin.html` | Организатор (PIN из `firebase-config.js`): открыть/закрыть приём, показать итоги на экране, выгрузка в Excel (CSV) и отчёт HTML, сброс |

На GitHub Pages адреса будут вида `https://<user>.github.io/<repo>/tl/`.
Если домен новый, добавьте его в Firebase → Authentication → Settings → Authorized domains.

## Вопросы

Редактируются в `tl/assets/tl-questions.js`. Типы: `text`, `long`, `single`, `multi`, `rank`.
Формулировки взяты из «Анкета_ТЛ.docx» плюс вопрос о компетенциях. Графики строятся только по вопросам с вариантами (объём, сквозные проекты, формат, рассрочка, приоритеты), открытые ответы показываются списком.

## Проверка без базы

Добавьте `?demo` к адресу (`admin.html?demo&seed` заполнит тестовыми ответами). В демо-режиме данные живут только в этом браузере.
